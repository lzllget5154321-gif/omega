# 09-功能基准任务花园（Functional Benchmark Garden）

> 本目录存放 Omega 系统的功能基准测试任务。它们是判断系统"是否更会做事"的客观度量。

## 核心理念

Functional Benchmark Garden 不是安全测试集（那是 V6 的做法），而是**能力测试集**——每次系统迭代后，跑一遍基准任务，看：
- 完成率是否提升？
- 完成时间是否缩短？
- 产出质量是否改善？
- 工具选择是否更准确？
- Skill 复用是否更高效？

## 基准任务池

### 闭环 1：网页/文章 → 知识入库
- **任务**：给定 3 篇不同来源的网页文章 → 提取 → 评级 → 创建 wiki/来源/ 页面
- **验收**：产出质量 > 人工操作的 70%（时间节省 > 50%）

### 闭环 2：PDF 文献处理
- **任务**：处理 5 篇 PubMed PDF → Zotero 条目 → L3 深度笔记 → 概念链接
- **验收**：5/5 PDF 成功提取，≥2 个概念触发 ≥2 规则

### 闭环 3：CSV 数据分析
- **任务**：读取 CSV → 探索性分析 → 统计检验 → 可视化 → 报告
- **验收**：分析正确+图表合理+报告可读

### 闭环 4：工具缺口检测 + 学习
- **任务**：故意要求使用一个系统未知的工具 → 检测缺口 → 搜索 → 试用 → 注册
- **验收**：成功发现+安装+试用+封装新工具

### 闭环 5：学术写作
- **任务**：基于 3 篇文献 → 写 1000 字综述草稿 → Critic 审查 → 修改
- **验收**：综述逻辑清晰+引用准确+格式规范

### 闭环 6：Computer Use 预填表单
- **任务**：打开指定网页 → 识别表单字段 → 预填 → 截图 → 等待确认
- **验收**：字段识别率 > 90%，预填准确率 > 80%

## 非学术基准任务（v1.1 新增）

> Omega 不能只测试医学/学术任务。以下非学术基准任务确保它真正成为**通用** AI 工具协调生态。

### 闭环 7：科学可视化动画制作
- **任务**：「制作细胞吞噬过程 AI 演示动画（2 分钟，面向医学生）」
- **阶段**：
  1. 科学内容核查（检索文献+提取关键事实）
  2. 编写分镜稿（12 镜头）+ 旁白稿
  3. 选择动画工具链（Manim / Blender / AI 视频生成）
  4. 生成动画草稿（至少 60 秒）
  5. 生成旁白音频（TTS）+ 字幕（SRT）
  6. 科学准确性审查 + 视觉质量审查
  7. 最终渲染 MP4 + 组装多模态成果包
- **验收**：完整成果包（MP4 + 分镜稿 + 旁白稿 + 源文件），科学准确性 ≥ 90%

### 闭环 8：商业汇报 PPT 制作
- **任务**：「根据这份数据报告，做一页商业汇报 PPT」
- **阶段**：数据提取 → 关键信息提炼 → 图表生成 → PPT 创建
- **验收**：PPT 可打开、图表正确、信息层次清晰

### 闭环 9：科普短视频剪辑
- **任务**：「给这段 5 分钟讲座视频加字幕，剪辑成 2 分钟精华版」
- **阶段**：语音识别 → 字幕生成 → 关键片段识别 → 剪辑 → 导出
- **验收**：字幕同步（偏差 < 0.5s）、精华版包含核心内容

### 闭环 10：工具对比报告
- **任务**：「对比 Blender 和 Manim 用于医学动画的优劣，生成对比报告」
- **阶段**：搜集资料 → 对比分析 → 生成报告 → 创建 wiki/对比/ 页面
- **验收**：对比维度 ≥ 8，每个维度有具体数据支撑

### 闭环 11：自动安装并试用新工具
- **任务**：「安装并试用 X 工具，生成试用报告」
- **阶段**：搜索 → 读文档 → 沙箱安装 → 运行示例 → 评估 → 生成报告
- **验收**：安装成功、运行至少 2 个示例、报告含优缺点和适用场景

### 闭环 12：根据截图生成操作说明
- **任务**：「根据这 5 张软件界面截图，生成操作说明书」
- **阶段**：截图 OCR → 界面元素识别 → 操作步骤推理 → 生成说明书
- **验收**：步骤完整、可执行、新用户能跟随操作

## 使用方式

```bash
# 跑全部基准任务
python scripts/run_benchmark_garden.py --all

# 跑特定闭环
python scripts/run_benchmark_garden.py --task knowledge_ingestion

# 比较两个版本的基准结果
python scripts/compare_benchmarks.py --v1 omega-v1.0 --v2 omega-v1.1
```
