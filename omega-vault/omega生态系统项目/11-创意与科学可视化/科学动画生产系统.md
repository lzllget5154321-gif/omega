# 科学动画生产系统

> **定位**：Omega 系统的一级功能域——创意与科学可视化生产。覆盖从科学内容核查到最终视频渲染的完整管线，让 Omega 不仅能做学术研究，还能制作医学教学动画、科学演示视频、科普内容。

---

## 一、功能域定义

| 维度 | 定义 |
|------|------|
| **域名称** | 创意与科学可视化（Creative & Scientific Visualization） |
| **服务对象** | 医学生教学、学术报告、科普传播、课程制作 |
| **核心能力** | 科学事实→视觉脚本→动画资产→动画制作→旁白字幕→审查→渲染发布 |
| **输出类型** | MP4 视频、分镜稿、旁白稿、字幕文件、源文件（.blend / .py）、素材资产 |
| **自主等级** | L2（最终成品需用户审核确认） |

## 二、生产管线

```
用户需求（一句话）
    │
    ↓
┌───────────────────────────────────────────────────────────┐
│ 阶段 1：研究（Research）                                    │
│   Researcher Agent                                         │
│   - 检索科学文献和参考材料                                  │
│   - 提取关键科学事实和步骤                                  │
│   - 收集视觉参考（教科书插图、已有动画、显微镜图像）         │
│   输出：科学研究简报（science_brief.md）                    │
└───────────────────────────┬───────────────────────────────┘
                            ↓
┌───────────────────────────────────────────────────────────┐
│ 阶段 2：脚本编写（Scripting）                               │
│   Storyboard Agent + Academic Writer                      │
│   - 将科学步骤转为镜头脚本                                 │
│   - 每个镜头：描述画面内容、持续时间、旁白文字、标注要点    │
│   - 编写旁白稿（面向目标受众的语言水平）                    │
│   输出：分镜稿（storyboard.md）+ 旁白稿（narration.md）     │
└───────────────────────────┬───────────────────────────────┘
                            ↓
┌───────────────────────────────────────────────────────────┐
│ 阶段 3：工具选择（Tool Selection）                          │
│   Stage-Aware Router（execution stage 权重）               │
│   - 根据动画类型选择最佳工具链                              │
│   - 2D 教学动画 → Manim (Python)                           │
│   - 3D 细胞动画 → Blender (Python API)                     │
│   - 快速草稿 → AI 视频生成 + 后期                           │
│   - 备选工具链就绪                                         │
│   输出：工具选择决策（tool_selection.md）                   │
└───────────────────────────┬───────────────────────────────┘
                            ↓
┌───────────────────────────────────────────────────────────┐
│ 阶段 4：资产准备（Asset Preparation）                       │
│   Asset Generation Agent                                  │
│   - 创建/获取视觉素材（细胞模型、蛋白质结构、背景等）       │
│   - AI 图像生成（如需要概念图）                             │
│   - 素材格式标准化                                         │
│   输出：素材清单 + 素材文件（assets/）                      │
└───────────────────────────┬───────────────────────────────┘
                            ↓
┌───────────────────────────────────────────────────────────┐
│ 阶段 5：动画制作（Animation）                               │
│   Animation Agent                                         │
│   - 按分镜稿逐镜头制作动画                                  │
│   - 编写 Blender Python 脚本 或 Manim Python 脚本           │
│   - 在沙箱中试渲染（验证可行性）                            │
│   - 生成动画草稿（draft.mp4）                              │
│   输出：动画源文件 + 草稿视频                               │
└───────────────────────────┬───────────────────────────────┘
                            ↓
┌───────────────────────────────────────────────────────────┐
│ 阶段 6：旁白与字幕（Narration & Subtitles）                │
│   Narration Agent + Subtitle Agent                        │
│   - TTS 生成旁白音频（根据旁白稿）                          │
│   - 生成字幕文件（.srt）                                   │
│   - 时间轴对齐（旁白↔字幕↔画面）                           │
│   输出：旁白音频 + 字幕文件                                 │
└───────────────────────────┬───────────────────────────────┘
                            ↓
┌───────────────────────────────────────────────────────────┐
│ 阶段 7：审查（Review）                                      │
│   Scientific Accuracy Critic + Aesthetic Critic            │
│   - 科学准确性审查：每个镜头的事实是否正确                  │
│   - 视觉质量审查：清晰度、色彩、标注可读性                  │
│   - 旁白字幕审查：语言准确性、时间同步                      │
│   输出：审查报告（review_report.md）                       │
└───────────────────────────┬───────────────────────────────┘
                            ↓
┌───────────────────────────────────────────────────────────┐
│ 阶段 8：最终渲染与交付（Final Render & Delivery）          │
│   Video Editing Agent + ffmpeg                            │
│   - 将视频+音频+字幕合成最终 MP4                            │
│   - 渲染多种分辨率（1080p + 720p）                         │
│   - 组装完整成果包                                         │
│   输出：Multimodal Outcome Package                         │
└───────────────────────────────────────────────────────────┘
```

## 三、工具链路线

### 路线 A：Manim 2D 教学动画（推荐用于数学/图解/流程动画）

```
适用场景：细胞过程示意图、数学公式演示、统计概念动画、流程图解
优点：精确可控、代码即动画、适合科学精确性要求高的场景
缺点：学习曲线陡、3D 能力有限

工具链：
  Python + Manim → MP4 输出
  + ffmpeg 后期处理
  + TTS 旁白
  + 字幕叠加

示例输出：
  phagocytosis_manim.py  ← 动画脚本（可复现）
  phagocytosis_draft.mp4 ← 草稿
  phagocytosis_final.mp4 ← 最终成品
```

### 路线 B：Blender 3D 动画（推荐用于细胞/分子/3D 教学动画）

```
适用场景：细胞结构、分子交互、器官解剖、3D 医学演示
优点：3D 逼真、物理模拟、Python API 完全可控
缺点：渲染时间长、需要资产准备、内存需求大

工具链：
  Blender + Python (bpy) → .blend 源文件
  + Eevee/Cycles 渲染器 → 视频帧
  + ffmpeg 合成 → MP4
  + TTS 旁白
  + 字幕叠加

示例输出：
  phagocytosis.blend       ← 3D 源文件
  phagocytosis_script.py   ← Blender Python 脚本
  materials/               ← 材质库
  textures/                ← 贴图
  rendered_frames/         ← 渲染帧序列
  phagocytosis_final.mp4   ← 最终成品
```

### 路线 C：AI 视频生成 + 后期（适合快速概念草稿）

```
适用场景：快速概念演示、风格探索、多版本草稿对比
优点：速度快、风格多样
缺点：科学准确性不可控、需要大量后期审查

工具链：
  Runway / Pika / Luma → AI 生成视频片段
  + ffmpeg 拼接
  + After Effects / DaVinci Resolve 后期
  + 人工审核每帧

注意：此路线适合快速探索，不适合最终科学教学成品。
      科学准确性必须由 Scientific Accuracy Critic 逐帧审查。
```

### 路线 D：混合路线（推荐用于复杂项目）

```
Manim 做 2D 图解层 + Blender 做 3D 主体 + ffmpeg 合成

示例：细胞吞噬动画
  - Blender 做 3D 细胞膜、伪足、溶酶体（主体动画）
  - Manim 做标注文字、箭头、步骤说明（图解覆盖层）
  - ffmpeg 合成两个视频流 + 旁白音频 + 字幕
```

## 四、相关 Agent 定义

### 4.1 Visualization Director（可视化导演）

```
生态位：视觉决策者。负责将科学内容转化为视觉策略。

核心能力：
- 决定用 2D/3D/混合路线
- 审阅分镜稿和视觉脚本
- 协调各制作 Agent 的工作流
- 最终视觉质量把关

持有能力类型：ReadLocalFormal, WriteDraft, InspectOperations
典型工具：Storyboard Agent, Animation Agent, Aesthetic Critic
自主等级：L2
```

### 4.2 Storyboard Agent（分镜 Agent）

```
生态位：脚本转化者。将科学事实转化为镜头语言。

核心能力：
- 解析科学研究简报
- 生成分镜稿（镜头号、画面描述、持续时间、旁白、标注）
- 计算总时长、检查是否符合目标时长
- 标注每个镜头需要的视觉资产

典型工具：Claude / GPT（文本生成）
自主等级：L1（分镜稿自动生成，最终由 Visualization Director 审阅）
```

### 4.3 Animation Agent（动画 Agent）

```
生态位：动画工匠。执行实际的动画制作。

核心能力：
- 编写 Blender Python 脚本 或 Manim Python 脚本
- 在沙箱中试渲染
- 根据审查反馈修改动画
- 管理渲染参数（分辨率、帧率、编码格式）

典型工具：Blender, Manim, ffmpeg
自主等级：L1（动画自动生成，最终由 Critic 审阅）
安全约束：所有渲染在 Docker 沙箱中执行
```

### 4.4 Asset Generation Agent（资产生成 Agent）

```
生态位：素材工匠。创建和准备视觉素材。

核心能力：
- AI 图像生成（DALL-E, Stable Diffusion, ComfyUI）
- 3D 模型搜索和转换（Sketchfab, TurboSquid）
- 素材格式标准化（分辨率、色彩空间、文件格式）
- 素材授权检查

典型工具：ComfyUI, Stable Diffusion, Blender
自主等级：L1
注意：AI 生成的医学图像必须经过 Scientific Accuracy Critic 审查
```

### 4.5 Narration Agent（旁白 Agent）

```
生态位：声音工匠。将旁白稿转化为音频。

核心能力：
- TTS 生成旁白（ElevenLabs / Edge TTS / OpenAI TTS）
- 语速和语调调整
- 时间轴标记（与画面和字幕对齐）
- 多语言支持（中英文旁白）

典型工具：Edge TTS（免费）, ElevenLabs API（高质量）, OpenAI TTS
自主等级：L1
```

### 4.6 Subtitle Agent（字幕 Agent）

```
生态位：字幕工匠。生成和同步字幕。

核心能力：
- 从旁白稿生成字幕（.srt / .ass）
- 时间轴对齐（语音识别或手动时间码）
- 关键步骤标注（覆盖在视频上）
- 多语言字幕

典型工具：whisper, ffmpeg subtitles filter
自主等级：L1
```

### 4.7 Scientific Accuracy Critic（科学准确性审查 Agent）

```
生态位：科学守门人。确保动画的科学准确性。

核心能力：
- 逐镜头检查生物学/医学事实
- 比对参考教材和文献
- 标注不准确或误导性的画面
- 提出修改建议

典型工具：Claude, 教科书/文献数据库
自主等级：L2（审查报告需用户确认）
关键约束：对医学动画有一票否决权（与 MEA 同级）
```

### 4.8 Aesthetic Critic（美学审查 Agent）

```
生态位：视觉把关。确保动画的视觉质量。

核心能力：
- 检查视觉清晰度（是否易于理解）
- 检查色彩搭配（对比度、色盲友好）
- 检查标注可读性（字号、字体、位置）
- 检查动画流畅度（帧率、过渡）

典型工具：Claude（视觉分析）+ ffprobe（技术参数）
自主等级：L1（审查报告自动生成）
```

## 五、工具替代链（动画制作）

```
Primary:    Blender (3D) / Manim (2D)
           ↓ 不可用？
Backup 1:  Manim (如 Primary 是 Blender，反之亦然)
           ↓ 不可用？
Backup 2:  PowerPoint + AI 图像生成 + ffmpeg 拼接
           ↓ 不可用？
Backup 3:  Runway / Pika / Luma AI 视频生成
           ↓ 不可用？
Fallback:  向用户报告工具链不可用，展示已完成的分镜稿和旁白稿，
           建议用户手动制作或等待工具恢复
```

## 六、基准任务：细胞吞噬 AI 演示动画

### 任务规格

```
Task: "制作 2 分钟细胞吞噬过程 AI 演示动画"
Audience: 医学生
Requirements: 科学准确、视觉清晰、旁白+字幕+关键步骤标注
Deliverables: MP4 + 分镜稿 + 旁白稿 + 源文件
```

### 预期 Omega 完成度

| 等级 | 实现 | 自动完成度 | 需要人工 |
|------|------|:--:|------|
| L1：脚本/分镜/旁白稿 | Claude + Researcher → 自动生成 | 90%+ | 事实核查 |
| L2：PPT/图文式动画 | File Editor + 图像生成 + ffmpeg | 80%+ | 视觉审查 |
| L3：Manim 2D 动画 | Manim Adapter + Python 脚本 | 70-85% | 视觉+科学审查 |
| L4：Blender 3D 动画 | Blender Adapter + Python 脚本 | 60-75% | 审美审核 |
| L5：商业级电影动画 | 全管线 + 专业资产 | 40-60% | 大量人工 |
